# react-select installation instructions

To use a modern, user-friendly multi-select dropdown in React, install the `react-select` package:

npm install react-select

# or, if using yarn:
yarn add react-select

After installing, you can import and use it in your components:

import Select from 'react-select';

// For multi-select:
<Select isMulti options={...} value={...} onChange={...} />
